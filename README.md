## Project overview (for admissions officer)

Bankist is a lightweight, single-page client-side banking simulation. It demonstrates UI design, DOM updates, internationalization, input handling, and small application logic such as transfers, loans, account closure, and an automatic logout timer.

## Primary user-visible features

- Secure-login simulation (username + PIN) with personalized welcome message.
- Display of account balance, movements (transactions) and human-friendly dates ("Today", "Yesterday", "X days ago").
- Transfer funds to another user (client-side only).
- Request a loan with a conditional approval rule.
- Close (delete) an account.
- Automatic logout timer for user session simulation.
- Currency formatting and locale-aware date/time formatting.
